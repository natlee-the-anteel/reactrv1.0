# Contributing

Thanks for your interest in `reactr`.

## Bug reports and feature requests

Please [open a GitHub issue](https://github.com/natlee-the-anteel/reactrv1.0/issues) for:
- Bugs or unexpected pipeline behavior
- Questions about configuring or running a specific analysis
- Feature requests or suggestions

When reporting a bug, please include:
- The rule/step that failed (e.g. from the Snakemake error output)
- Your `config.yaml` (redact anything sensitive)
- The relevant log output

## Pull requests

`reactr` is not currently accepting pull requests. The codebase is actively
under development by a single maintainer, and external code changes can't
be reviewed or merged at this time. If you have a fix or improvement in
mind, please open an issue describing it instead — that's the best way
to flag it for future consideration.

This may change as the project matures.
